## 👋 Sobre mí

Soy **Jhoan Felipe León**, odontólogo y desarrollador. Uno la práctica clínica con la ingeniería de software para crear herramientas de **salud digital** que cumplen la normativa colombiana y que un profesional de la salud realmente quiere usar.

- 🦷 Construyo **DentalHC**, una historia clínica odontológica electrónica (odontograma anatómico, RIPS, facturación electrónica, inventario).
- 🏥 Trabajo en **Habilita Salud**, una guía para la habilitación de prestadores (Res. 3100/2019).
- 🧠 Me interesan la **visión por computador**, las redes neuronales y la imagen diagnóstica (CBCT / DICOM).
- 🤖 Desarrollo con flujos **agénticos de IA** (Claude Code, agentes por ámbito: clínico, legal, financiero, QA).
